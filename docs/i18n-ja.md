# 일본어(ja) 현지화

화면 문구는 모듈마다 `composeResources/values/strings.xml`(한국어, 기본)과 `values-ja/strings.xml`(일본어)에 둔다. 앱 모듈은
`composeApp/src/main/res/values(-ja)/strings.xml`이다. 한국어 문구를 바꾸면 같은 커밋에서 일본어도 고친다. 지금은 일본어 화면만
있고 데이터는 한국 샤드다(사용자 결정, 2026-10-04). AP 샤드는 Riot 승인 뒤 제품 설명을 고칠 때 붙인다.

## 언제 일본어가 뜨나

앱 안에 언어 고르는 메뉴는 없다. 안드로이드가 고른 앱 언어를 따른다.

- 기기 언어가 일본어면 일본어다.
- 안드로이드 13부터는 설정 > 앱 > 오발있 > 언어에서 앱만 일본어로 고를 수 있다. `generateLocaleConfig`가 이 목록을 만든다.
- 한국어와 일본어가 아닌 언어(영어 등)는 기본인 한국어로 뜬다.
- 앱이 켜진 채로 바꾸면 화면이 다시 만들어지며 바로 바뀐다(`AppLanguage`).
- 개발 중에는 `adb shell cmd locale set-app-locales com.ovalit --locales ja-JP`로 바꾸고 `--locales ""`로 되돌린다.

화면에 뜨는 사람 이름(Riot ID, 친구 이름)은 데이터라 번역하지 않는다. 가짜 저장소의 이름이 한국어인 건 그래서다.

## 지키는 것

- 말투는 です・ます체다. 「〜でございます」, 「様」는 쓰지 않는다. 앱 이름 풀이(「今日ヴァロやる人いる？」)와 인트로 헤드라인만
  반말로 둔다.
- 「。」는 문단(시트·설정 설명, 표 밑 안내, 확인 창 본문)에만 찍는다. 제목, 헤드라인, 버튼, 칸 이름, 한 줄 안내에는 찍지 않는다.
  물음표는 전각 「？」다. 숫자와 라틴 문자는 반각이다.
- 「おすすめ」는 쓰지 않고 「〜を使いましょう」처럼 결정을 대신하는 말도 쓰지 않는다(CLAUDE.md 지켜야 할 선). 「反省」 대신
  「振り返り」다.
- 이름 뒤에 「さん」을 붙이지 않는다. 일본어 조사는 이름에 따라 바뀌지 않아 문장 틀에 직접 쓴다. 한국어에서 코드가 조사를
  붙이던 자리(`withLocalJosa`)는 일본어에서 이름만 넘어온다.
- 자리 표시(`%1$s`, `%2$d`)와 XML 이스케이프(`&#160;` 등)는 그대로 둔다. 어순이 바뀌면 번호로 자리를 옮긴다.
- Riot 고지(`riot_disclaimer`)는 영문 원문이라 `values-ja`에 넣지 않는다.
- `text_locale`은 `ja-JP`, `josa_enabled`는 `false`, `list_separator`는 `、`다.

## 일본 사용자에게 물을 것

- 初動(첫 교전)이 자연스러운지
- 세 칸 격자에서 꺾이는 긴 칸 이름: ファーストキル勝率, ラウンド平均アシスト, トレードされたデス. 하나가 꺾이면 모든 칸이 두
  줄이 된다. FK勝率 같은 줄임말을 쓸지
- S3 펼친 줄의 ファーストキル, ファーストデス가 9sp 안팎까지 줄어드는 것. 대안은 FK, FD
- S3 맞대결 30dp 열의 アシ

## 아직 한국어인 것

- 서버의 초대 페이지와 로그인 완료 페이지(`server/src/routes/public.ts`, `auth.ts`)
- 서버가 내려줄 티어 표(`server/src/data/tiers.json`)와 콘텐츠 카탈로그(`locale=ko-KR`). 가짜 저장소는 `FakeNamesJa`로 대신한다.
- 스토어 등록 정보, 개인정보처리방침
- Pretendard에는 한자가 없어 한자는 시스템 글꼴로 그린다. `text_locale`이 `ja-JP`라 일본 자형이 나온다.
