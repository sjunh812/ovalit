# Quickstart: 오발있 기준 스펙 돌려 보기

사용자 이야기마다 앱이 스펙대로 움직이는지 확인하는 순서다. 프로덕션 키가 나오기 전이라 앱은 가짜 서버(`FakeMatchRemoteSource`)와
메모리 저장으로 돌고 S0-3 Riot 로그인은 건너뛴다. 실제 서버를 붙인 뒤에는 같은 순서를 실제 계정으로 다시 돈다.

## 준비

- JDK 17, Android SDK(compileSdk 37), Node 22 이상.
- `local.properties`에 `sdk.dir`. Firebase와 광고 ID는 없어도 빌드된다(그 기능 없이 돈다).
- 기기는 에뮬레이터를 쓴다. `installDebug`는 붙은 모든 기기에 깔리니 `ANDROID_SERIAL`을 지정한다.

## 자동 검사

```bash
./gradlew testAndroidHostTest
```

```bash
./gradlew iosSimulatorArm64Test
```

```bash
cd server && npm ci && npm run typecheck && npm test
```

세 묶음은 CI(`.github/workflows/ci.yml`)와 같다. 지표 계산(`core/model`), 받기 규칙(`OfflineFirstMatchRepositoryTest`), 옮겨
담기(`core/network`), 화면(`iosTest`), 서버의 지키는 선(`policy.test.ts`, `friends.test.ts` 등)이 여기서 돈다.

## 앱 띄우기

```bash
ANDROID_SERIAL=emulator-5554 ./gradlew :composeApp:installDebug
```

끊김을 볼 때는 Build Variants에서 `benchmark`를 고른다. 디버그 빌드는 Compose가 몇 배 느려 릴리스에 없는 끊김이 보인다.

서버를 같이 돌려 친구와 ㅇㅂㅇ 흐름을 볼 때:

```bash
cd server && npm install && npm run db:migrate:local && npm run dev
```

로컬 서버는 `DEV_LOGIN=true`일 때 `/auth/dev`로 RSO 없이 계정을 만든다(`server/README.md`).

## 이야기마다 확인할 것

### P1 연동하고 이번 주 리포트를 본다

1. 앱을 처음 열면 인트로에 로고, "오늘 발로란트 할 사람 있어?", 영문 비공식 고지가 보인다.
2. 연동 동의에서 계속하면 S0-4에서 관심사를 고르는 동안 50칸이 이기면 초록, 지면 빨강으로 찬다. 집계 숫자는 다 받은 뒤 한 번만 뜬다.
3. 홈에 기간 이름, 역할 비중, 승패 칸, 짚을 점, 고정 칸 다섯(피해량, K/D, KDA, 전투점수, 헤드샷 순), 달라진 점이 보인다.
4. 고정 칸 숫자 밑 변화량이 오르면 초록, 내리면 빨강이고 퍼센트 지표는 `%p`다. 칸을 누르면 S1-a 시트에 표본, 8주 막대, 평소
   범위, 계산식이 있다.
5. 설정에서 저장된 데이터를 지우면 홈이 "저장된 경기가 없어요"와 "다시 불러오기"가 된다.

기대 결과: 같은 가짜 50경기로 손으로 센 값과 화면 숫자가 보이는 자릿수로 같다(SC-005). 종합 점수나 남과의 순위는 어디에도 없다.

### P2 지난 경기를 돌아본다

1. 경기 탭에서 날짜 머리 뒤에 "오늘 · 2승 1패"가 보인다.
2. 당기면 "새 경기 N판을 불러왔어요"가 뜬다. 가짜 서버는 당기면 늘 한 판을 주고 30초마다 한 판이 끝난 것으로 쳐서, "새로 끝난
   경기가 없어요"는 실제 서버를 붙인 뒤에 확인한다. 10분 넘게 앱을 떠났다 오면 스무 판이 넘게 쌓여 칩 밑에 진행 줄이 뜬다.
3. 경기를 열어 스코어보드, 라운드, 내 기록 세 탭을 오간다. 라운드 탭에 구매 유형별 승패가 있다.
4. 요원이나 맵으로 거르면 날짜 머리 승패도 보이는 경기만 센다.

기대 결과: 이미 받은 경기는 다시 받지 않는다(SC-006, 받기 테스트가 지킨다).

### P3 내 기록을 모아 본다

1. 홈 오른쪽 위 아바타로 내 프로필을 연다. 티어 카드, 통계, 맞힌 부위, 요원, 무기, 최근 경기가 있다.
2. 요원 화면(S7)에서 주 역할 비중과 역할에 맞는 두 열이 먼저 보인다.

### P4 친구를 맺고 견준다

앱은 아직 가짜 친구 저장소(`FakeFriendRepository`)로 돌아서 화면은 앱에서, 서버 규칙은 로컬 서버에서 따로 본다.

1. 앱: S3 스코어보드에서 이름을 누르면 앱을 쓰는 사람은 친구 요청 시트, 아니면 초대 링크 시트가 뜬다.
2. 앱: S5에서 친구를 라이벌로 고르면 홈의 유도 칸 자리에 라이벌 대결 칸이 생기고 "5개 중 N개 앞섬"만 센다.
3. 서버: 로컬 서버에 `/auth/dev`로 계정 둘을 만들고 같이 뛴 경기 ID로 `POST /friends/requests`를 보낸 뒤 수락한다. 같이 뛰지
   않은 경기로 보내면 막힌다.

기대 결과: 같이 뛰지 않은 사람에게는 요청이 들어가지 않고 전적을 끈 친구의 경기는 내려오지 않는다(`friends.test.ts`). Riot
ID로 사람을 찾는 경로가 없다(`policy.test.ts`).

### P5 친구를 불러 같이 한다

앱은 가짜 ㅇㅂㅇ 저장소(`FakePingRepository`)로 돈다.

1. 친구 탭의 "파티 모집"에서 친구를 고르고 시각을 정해 부른다. 글을 쓰는 칸이 없다.
2. 받은 초대에서 "다른 시간"을 고르면 정해진 시각부터 30분 단위로 고른다.
3. 서버: `POST /pings`, `POST /pings/:id/reply`로 다른 시간을 제안하고 호스트가 `POST /pings/:id/time`으로 받아들이면 그 친구는
   `yes`, 나머지는 `pending`으로 돌아간다(`pings.test.ts`).

### P6 데이터와 공개 범위를 관리한다

1. 설정에서 전적 공개, 알림, 관심사, 기본 큐를 바꾼다. 기본 큐를 바꾸면 앱을 새로 열 때 홈 칩이 그 큐다.
2. 설정 맨 아래에 영문 비공식 고지가 있다.
3. 연동을 해제하면 인트로로 돌아간다.
4. 서버: `DELETE /me` 뒤 로컬 D1에서 그 사용자의 세션, 친구, 요청, 초대(`me.test.ts`)와 ㅇㅂㅇ, 기기 토큰(`pings.test.ts`)이
   사라진다. 경기 참가 기록(`match_players`)은 다른 사람의 친구 확인에 쓰여 남고 10주 뒤 크론이 지운다(`match-players.test.ts`).

## 실제 서버를 붙인 뒤

[research.md](research.md)의 열린 결정을 닫은 뒤 위 순서를 실제 계정으로 돈다. 그때 SC-001(첫 수집 1분 안팎)과 SC-007(통계·오류
보고에 Riot 값 0건)을 실제 값으로 잰다.

로컬 DB를 붙인 뒤에는 FR-036을 본다. 비행기 모드로 앱을 다시 켜도 주간 리포트, 경기 목록, 내 프로필이 저장된 경기로 보이고, 당기면
"인터넷에 연결되어 있지 않아요"가 한 줄 뜬다. 지금은 메모리 저장이라 다시 켜면 인트로부터 시작한다.
